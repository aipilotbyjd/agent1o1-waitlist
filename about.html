About

It's one person. That's not a disclaimer — it's most of the point.

I'm Jaydeep. I build software in India.

Agent1o1 started because I kept writing the same thing over and over: a script that called an AI model, did something with the answer, and ran on a schedule. Every time, I'd rebuild the same scaffolding. Retries. Logging. What happens when the model returns the wrong shape. What happens when it silently starts returning worse answers and nobody notices for a month.

The interesting part was never the AI call. It was everything around it.

So I built the everything-around-it, properly, first. A real execution engine — steps that run in the right order, that never fire twice by accident, that pin themselves to a version so an edit doesn't break a job already running. Then I put a canvas on top of it.

What I believe about this

Anyone can put a text box on a canvas. Making it still be running in six months is the hard part, and that's where the months went.

You should be able to see what it costs before you press run. The whole industry hides this. There's no good reason for it.

The steps that don't cost me money shouldn't cost you money. Loops, branches, webhooks — free, permanently.

If something breaks, you should know which step and why. Never "Workflow failed."

How I work

I ship every week and write about it, including the weeks that go badly. There's no team, no investors, no board asking for a growth chart. That means fewer features than the funded competition, and it means I answer my own email.

I don't know if this becomes a company. I know the thing I've built works, and I know I wanted it to exist.

Want to see what's shipping? Read the changelog. Want to argue with me about any of this? jaydeep@agent1o1.com — you'll get me, not a ticket queue.
